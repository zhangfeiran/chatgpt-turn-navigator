## 安装 / 更新

在 Tampermonkey 中打开原来的脚本，用本包根目录 `chatgpt-turn-navigator.user.js` 的全部源码覆盖，保存，然后刷新 ChatGPT。仅保留一个版本启用。

安装只需要这一个 `.user.js`，无需安装 `src` 或运行构建命令。本版保留旧版的位置、宽高、折叠设置和展开方式；没有迁移或清空这些设置。

## 本地 Markdown 自动同步（v2.0.0）

首次在目录面板的 ⚙ 设置中点击「选择目录」，通过浏览器目录选择器授权一个专用于归档的本地目录。授权后自动同步打开过且已取得正文的私人对话：在所选目录内建立 **ChatGPT Markdown** 子目录，再按对话标题及完整对话 ID 分文件夹。支持手动「立即同步」、「暂停同步」、「恢复/授权」和「解除绑定」。

- 每个已取得的 Q/A 对应一份 Markdown（提问、回答、原对话链接、可取得的消息时间）。助手独立回复也可单独归档。保留现有公式、代码、Mermaid 转换规则。
- v2.0.1 起，新文件使用 `YYYY-MM-DD_HH-mm-ssZ - 提问摘要 -- 回答ID.md`：优先取原始提问时间、轮次时间，或已知的回答时间（UTC）。无法取得消息时间时，文件名标注 `_首次归档`，不将归档时间冒充消息时间。旧编号文件及已建立的文件名仍按稳定 ID 更新，不自动改名、复制或删除；文件夹保持稳定。_index.md 按本次已知对话顺序列出归档，并保留其他历史/分支文件的链接。
- 回答停止生成并稳定后自动写入；未变内容不重写，重新生成的不同回答 ID 保留为独立文件。仅在文件的归档标识和 SHA-256 完整性检查通过时更新，手动修改、同名冲突、旧分支文件和更完整的旧归档不会被强制覆盖。自动生成的 _index.md 同样受保护。
- 默认关闭；通过 File System Access API 写入本地目录，IndexedDB 保存目录句柄和授权偏好，重新打开时仍取决于浏览器授予的权限。不同标签页通过 Web Locks 串行写入。选择目录是显式授权；解除绑定不删除文件，也不主动撤销浏览器站点权限。
- 目前适用于支持目录选择、Web Locks 和 Web Crypto 的桌面 Chromium 浏览器（如 Chrome / Edge）。仅同步网页打开时脚本已取得的内容；不会自动遍历全部账号历史、后台打开其他会话、滚动扫描或在网页关闭后工作。未取得稳定消息 ID、提问或回答的轮次先跳过；部分代码/图表和附件会标记为部分，不保证完整历史。请保留原对话作为依据。
- 目录同步为单向归档，不会将本地编辑同步回 ChatGPT。建议选择专用目录，不要选择公开共享或云同步目录，除非你明确希望这些对话也由相应软件同步。

## v2.0.1 导航条与按钮修复

历史尚未确认时，收起面板后的导航条显示滚动容器的实际位置百分比，而非把少量挂载轮次当作完整历史；即使只识别到一轮长回答也可显示和定位。历史确认且有多轮时保留原先的轮次导航。导出整个对话按钮始终显示单个下载图标，状态文字移至悬停提示与操作反馈；诊断版本号由构建版本生成。

## 新增的操作

| 功能 | 操作 |
|---|---|
| 复制 / 下载某轮 Q/A | 提问右侧 `MD▾`；Shift+点击直接复制 |
| 只复制 / 下载一个回答 | 对应「回答目录」右侧 `⋯`；`↥` 仍跳到回答开头 |
| 一键复制当前 Q/A | 面板底部 `⧉ 复制当前 Q/A` |
| 下载整个对话 | 面板底部 `↓ 导出整个对话` |
| 复制整个对话 | Shift+点击底部 `↓ 导出整个对话` |
| 搜索已取得的正文 | 搜索框下方把「提问 / 标题」切换为「已缓存正文」 |
| 恢复阅读位置 | 底部 `↩ 继续上次阅读`；不会在打开网页时自动抢滚动 |
| 清除阅读记录 | 设置中的「清除阅读记录」，仅清除当前对话 |
| 扫描位置和顺序 | 设置中的「↕ 扫描校正排序」；再次点击停止 |

浏览器拒绝自动复制时，面板会显示完整 Markdown 文本框，可全选后按 Ctrl+C / ⌘C。复制与下载使用同一套内容处理。

正文搜索只检索本标签页已经取得的正文。状态条分别显示索引数量、挂载数量、正文缓存覆盖量和历史是否已确认。缓存数量表示至少取得了该轮的部分正文，不是完整性证明。正文命中摘要下方的轮次按钮定位到该轮开头，不承诺定位到每个单词。

## 整个对话 Markdown 导出标题层级（v1.9.3）

仅在**整个对话导出或复制**时，对标题结构做统一调整：对话标题用 `#`，每轮 `## 第 X 轮`；“提问”“回答”使用加粗标签（不是 `###` 标题）；每条回答的原始最高一级标题自动转换为 `###`，更深级别依次递增。例如原始 H2/H3 变成 H3/H4。无标题回答保持正文原样。

正文标题按每个回答独立计算，只调整真实 Markdown 标题，不改变代码围栏、数学公式、引用块或缩进代码中的 `#`。Markdown 的 ATX 标题最高只支持 H6，因此极深层标题会限制在 H6。**单轮 Q/A 和仅回答导出的旧格式不变**。

## 导航与原有交互

灰色轮次优先使用已记录位置接近目标，再按消息 ID 精确定位；找不到不会报告为成功。扫描、返回、加载更早和点击跳转共享一个控制器。新导航、正文滚轮/触摸、正文上的 Home/End/PageUp/PageDown 等键以及 Escape 会取消旧操作；被新操作接管的扫描不能再把正文拉回旧位置。明确点击「停止扫描」会尝试恢复扫描前位置。

鼠标悬停临时展开；点击刻度条或目录内容后固定展开；顶部按钮、× 或 Escape 关闭。拖动标题栏只上下移动，右侧始终贴边；左下角调整尺寸。

默认宽 360px、设定高 950px、顶部 5%、底部至少 5%，高度设置上限 1100px。视口不足时临时缩短，不改写偏好高度。回答 TOC **默认折叠**；只有手动点击某条回答的「回答目录」展开后，才显示 H1 目录层级并随着正文滚动展开当前章节的子标题，离开后自动收回。手动展开或折叠的章节仍优先并被记住；每条回答的 H1/H2/H3 按钮可锁定深度，再次点击当前深度可恢复自动跟随。标题栏「↵」可切换提问与 TOC 标题是否完整换行显示，设置保存在浏览器中。搜索临时展开，清空后恢复。

快捷键仍为 Alt+Shift+J 显示/隐藏、Alt+Shift+F 搜索、Alt+Shift+↑/↓ 上一轮/下一轮。

## 实现改进

- 位置记录带布局版本，不把不同页面高度下的比例坐标混合排序；已经观察到的先后关系可以跨坐标失效继续保留。
- 正文容器尚未挂载时先等待，随后自动恢复识别。
- TOC 与 Markdown 快照按消息变更更新，未变化的回答不再反复克隆标题或序列化 `innerHTML`；虚拟化卸载不等于删除。
- 404/410 明确不可用的历史接口有冷却，单轮完整正文已缓存时不再为复制/下载强制重新请求历史。手动「重新读取目录」仍可重试。
- API 分组优先使用轮次、任务运行和父子关系，可穿过隐藏分析/工具节点找到可见提问；隐藏内容本身不会导出。
- 新版 HTML 的 `data-response-body` 回答身份、`data-math-source` 公式和 `data-markdown-copy="inline-code"` 行内代码纳入适配。

## 代码块导出（v1.9.6）

Markdown 下载与复制优先读取 ChatGPT 代码块的完整复制源码属性，其次读取传统代码查看器或编辑器。保留语言、缩进、换行和字面字符，不导出 Python 等语言标签或复制/运行工具栏。若只能取得虚拟化编辑器的部分源码或无法取得源码，将明确标记为部分导出，并在缺失位置提示重新加载。

## Mermaid 与 Markdown 排版（v1.9.7）

Mermaid 预览优先导出可取得的原始源码为 `mermaid` 围栏代码块（包括源码属性、源码视图及当前图表组件的局部属性；后者为可选兼容路径）。只有渲染 SVG 时，仅对能可靠识别节点、标签和连线的简单流程图提供明确标注的重建源码；不把重建内容冒充原文，也不猜测复杂图形。无法还原的图会提示源码缺失。导出不会自动操作图表菜单、读取剪贴板或访问其他消息。

DOM 转换同时合并相邻的同类强调标记，并减少段落间的冗余空行，保留代码围栏与显示公式内部空白。

## 隐私与限制

无远程依赖、无第三方上传、无新增 Tampermonkey 权限。可选历史读取只访问当前 ChatGPT 站点；身份认证沿用原有读取方式。

默认关闭本地同步时，脚本的聊天正文与章节文字缓存只存在当前标签页内存。开启同步后，取得的正文按上述规则写入你授权的本地文件夹。布局保存在 localStorage，折叠状态使用 sessionStorage。阅读恢复另在 localStorage 中最多保存 40 个对话的消息 ID、章节哈希、偏移和时间，不保存提问、回答或章节原文。阅读记录是一次手动阅读后的定位信息，不是全文离线缓存。

完整历史接口仍可能不可用。扫描只表示遍历了当时可以加载的正文，不保证所有历史已出现；未取得的历史不能凭空补全。全对话导出无法确认完整时仍标为「部分」，缺失正文会明确说明。图片、附件、音视频和交互卡片不会打包进 Markdown。

编辑历史、切换分支后，若历史接口始终不可用，可能需要刷新网页重建本标签页索引。阅读记录指向的消息/章节已被替换或删除时，恢复可能失败；脚本不会故意改跳到同名但不同身份的回答。

## 模块化源码与构建

`src` 下包含 23 个功能模块；核心内容版本、导航所有权、排序关系、几何证据和阅读存储拥有各自的私有状态。其余页面兼容和 UI 代码通过同一词法调度层连接，保留已验证的行为，不是引入框架的全量重写。

```sh
python build.py
node --check chatgpt-turn-navigator.user.js
```

构建只需要 Python 标准库；`node --check` 是可选语法检查。输出是一份固定文件名的可安装脚本，不再生成版本化 TXT。模块顺序见 `build-manifest.json`，构建不访问网络。

测试代码见 `tests`，结果与边界见 `TEST_REPORT.txt`。测试需要本机已有的 Playwright、Chromium 与 BeautifulSoup；浏览器网络、会话路由和存储使用测试替身，不连接用户账号。用户保存的私有 HTML 没有放进安装包；可通过 `NAV_FIXTURES` 指向自己的 fixture 目录重跑可选真实结构测试。
